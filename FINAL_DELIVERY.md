## 🚨 TROUBLESHOOTING

### npm install slow?
```bash
npm install --no-audit
```

### Can't login to admin?
- Check .env ADMIN_PASSWORD
- Make sure it's saved

### WhatsApp not opening?
- Check .env WHATSAPP_NUMBER
- Format: +91-XXXXXXXXXX (with country code)

### Product photos not uploading?
- Cloudflare R2 auto-creates on first upload
- Or create manually on Cloudflare dashboard
